# Hierarchical Clustering Explained: Mall Customers Case Study

A static educational website (HTML, CSS, vanilla JavaScript, MathJax) teaching hierarchical clustering with one real dataset and eight graphs generated by Python.

## Learning objectives
Understand agglomerative vs divisive clustering, distance metrics, linkage methods, dendrograms, choosing k, scaling, evaluation (silhouette, Davies-Bouldin, cophenetic correlation) and common mistakes.

## Features
Responsive layout, table of contents with scroll-spy, graph gallery, collapsible interview answers, dataset download links, MathJax formulas.

## Project structure
```
index.html  css/style.css  js/main.js
data/Mall_Customers.csv
assets/images/*.png  (8 graphs)
generate_graphs.py   requirements.txt   results.json (written by the script)
```

## Dataset
Mall Customer Segmentation (Kaggle: https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python). 200 rows; columns CustomerID, Gender, Age, Annual Income (k$), Spending Score (1-100); no missing values. Clustering uses income and spending score (standardised); CustomerID is excluded.
Note: the bundled CSV was obtained from a public GitHub mirror of the Kaggle file (tirthajyoti/Machine-Learning-with-Python). To use the original, download it from Kaggle and replace `data/Mall_Customers.csv`.

## Setup and graph generation
```
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python generate_graphs.py
```
The script prints dataset checks, writes the PNGs to `assets/images/` and the numbers to `results.json`. Numbers quoted in the article text came from that file (tested with scikit-learn 1.8, SciPy 1.17); if you change library versions or settings, re-check the text against `results.json`.

## Run locally
`python -m http.server 8000` then open http://localhost:8000

## Deploy on Netlify
1. Create a GitHub repository and upload every file above.

3. In Netlify: Add new site, Import an existing project, choose the repository.
4. Build command: empty. Publish directory: `.` (root).
5. Deploy, then test navigation, all 8 images, formulas and the dataset download.
